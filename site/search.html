      Off-campus

      校外連線（EZproxy）

      填入學校圖書館的 EZproxy 前綴後，標示 🔒 的資料庫會透過學校登入開啟。留空就直接連線（在校內網路通常已有權限）。

      怎麼找到前綴？
      1. 最快：問學校圖書館「校外連線資料庫的 EZproxy 前綴是什麼」。
      2. 自己看：在校外從圖書館網站的資料庫清單點進 CINAHL 或 UpToDate，登入後看網址列。如果長得像 https://（某個網址）/login?url=https://www.uptodate.com/…，就複製開頭到 url= 為止（含 url=）。
      3. 如果網址變成 www-uptodate-com.（學校網域） 這種改寫網域的形式，代表學校只提供這種方式，這裡的前綴不適用：請從圖書館網站進入資料庫。

      本頁不會猜你的學校前綴，也不會把它送到任何地方；只存在這台裝置。

      網址格式與狀態（連結壞了請回報）

      每個網址都在 GitHub Actions 上實際連線測試（2026-10-08，之後每週自動重測）。確定＝實測帶得進檢索詞的搜尋網址；推測＝要先登入、無法實測到結果頁，開啟時也會複製檢索詞，沒帶入就直接貼上；首頁＝網站沒有可靠的搜尋網址，開首頁並複製檢索詞。「CI 實測」：OK＝有結果頁（首頁類＝首頁可開）；需登入＝轉到訂閱資料庫的登入頁（預期）；被擋＝網站擋掉雲端主機的自動連線，無法自動判斷，在一般瀏覽器通常正常。發現打不開或沒帶入檢索詞，請到 GitHub Issues 回報。

      資料庫狀態權限開啟的網址（{q}＝檢索詞）
      本頁不會把檢索詞送到任何伺服器，只是幫你開啟各資料庫的搜尋網址。各資料庫的檢索語法不同，PubMed 的欄位標籤不能直接用在其他資料庫。 Zotero Bridge · 說明
