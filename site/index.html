交班單Zotero 10 外掛 · 筆記到 Obsidian／Notion

雜事交班給它，
找文獻和寫作留給你。

ZotMax 把你在 Zotero 收的文獻、劃線和評讀，整理進你自己的 Obsidian 或 Notion，順手記下讀到哪、評到哪。要讀哪幾篇、每一題怎麼評、論文怎麼寫，還是你決定。

交給 ZotMax

  • 書目、劃線、Zotero 筆記同步到 Obsidian／Notion，重新同步不蓋掉你寫的內容
  • 閱讀狀態（待讀、已讀、已引用）在 Zotero、Obsidian、Notion 保持一致
  • CASP／JBI 評讀表記下你的每一題答案與根據，雙人評讀算 Cohen's κ
  • 回顧篩選的 PRISMA 2020 計數與流程圖
  • APA 7 引文由 Zotero 產生，不讓 AI 編參考文獻

留給你

  • 決定問題、找文獻、訂納入排除
  • 讀全文，自己回答每一題評讀
  • 寫文獻探討、實證報告和論文
研究生引導預設
開始安裝（約 15 分鐘） 下載最新版 .xpi

Zotero 10（Windows／macOS）· Obsidian 1.14 以上或 Notion 免費版 · AI 功能要自備 API 金鑰，依用量付費

每個功能都能關，新使用者從「研究生引導」開始

會替你找文獻、替你寫的功能，在「研究生引導」都先關著；想全部打開就選「進階」。改了任何一個開關，組合就會顯示「自訂」。都在 Zotero 設定 › ZotMax 裡切換，隨時改得回來。

還沒裝外掛，這兩頁也能先用

  • 醫學文獻快速搜尋一個檢索詞開 PubMed、CINAHL、Cochrane、華藝等 19 個資料庫；PICO 組 PubMed／CINAHL 檢索式；可設學校 EZproxy。

兩頁都不會把你輸入的內容送到任何伺服器，資料只存在這台裝置的瀏覽器。

怎麼確認它真的能用

每次改程式，GitHub Actions 都會把外掛裝進真正的 Zotero 10，檢查選單、設定頁、同步到 Obsidian、閱讀狀態、PRISMA 篩選等（不連 Notion、不呼叫真的 AI）：e2e 紀錄。

搜尋頁的資料庫網址每週一自動實際連線一次：link-check 紀錄。遇到問題請到 GitHub Issues 回報。

    下載 ZotMax 的 .xpi 檔

    1. 打開最新版的下載頁。 打開最新版下載頁 https://github.com/bobyu89/zotero-bridge/releases/latest

    打勾確認

    準備一個 Obsidian vault

    Vault 就是 Obsidian 存筆記的資料夾。ZotMax 會把文獻筆記寫進 vault 裡的 Zotero 子資料夾，你自己的筆記不會被動到。

    1. 還沒有 Obsidian：到官網下載安裝（免費）。版本要 1.14 以上才有彩色劃線與閱讀進度看板，可在 設定›關於 查版本。 https://obsidian.md/download
    2. 打開 Obsidian，按 建立新的 vault（Create new vault），取個名字，例如 研究筆記，選好要放在哪裡，按建立。已經有 vault 就直接用。
    3. 記下 vault 資料夾的位置，等一下 Zotero 裡的精靈會請你選它。要選的是 vault 的根目錄（裡面有 .obsidian 隱藏資料夾的那一層），例如 C:\Users\你的名字\Documents\研究筆記~/Documents/研究筆記。 忘了放哪裡：在 Obsidian 左下角按 vault 名稱 › 管理 vault…，清單裡每個 vault 下面就是它的位置。
    打勾確認

    建立 Notion integration 和文獻資料庫

    Integration 是 Notion 給外部程式的通行證，ZotMax 拿著它才能寫進你分享給它的資料庫。這一步要準備好兩樣東西：token 和資料庫連結，先貼在記事本裡。

    A. 建立 integration

    1. 打開 Notion 的 integration 頁面，按 New integration。 https://www.notion.so/profile/integrations
    2. 名稱填 ZotMax，類型選 Internal，選你的工作區，按儲存。
    3. 在 Internal Integration Secret 按 Show，複製 ntn_ 開頭的 token。它跟密碼一樣，不要貼到公開的地方。

    B. 建立資料庫並分享給 integration

    1. 在 Notion 新增一個空白的 Database（Table），例如命名 Zotero 文獻資料庫。欄位不用自己建，ZotMax 之後會自動補齊。已經有就直接用。
    2. 打開資料庫，右上角 ••• › Connections，加入剛剛的 ZotMax。少了這一步，ZotMax 沒有權限寫入。
    3. 右上角 ••• › Copy link，把資料庫連結也貼到記事本。

    申請 AI 的 API 金鑰

    AI 會讀書目、摘要、全文和你的劃線，寫成固定格式的研讀筆記；每篇只產生一次，之後同步會沿用。筆記是幫你回想，不是替你讀。

    這會花錢：Claude Pro、ChatGPT Plus 這類訂閱方案不能用在這裡。這裡要的是 API 金鑰，依用量另外計費，要先在平台儲值或綁卡。ZotMax 一次替超過 5 篇產生 AI 筆記前會先問你，花了多少看 設定 › ZotMax › AI ›「本月 AI 用量」（估計值，以平台帳單為準）。

    1. 到 Claude 的 API 平台登入，先在 Billing 儲值。 https://console.anthropic.com
    2. 到 API Keys › Create Key，複製 sk-ant- 開頭的金鑰。它只會顯示一次，先存在密碼管理程式或記事本。
    1. 到 OpenAI 的 API 平台登入，先在 Billing 儲值。 https://platform.openai.com/api-keys
    2. 按 Create new secret key，複製 sk- 開頭的金鑰。它只會顯示一次，先存在密碼管理程式或記事本。

    裝好 ZotMax 後，金鑰貼在 設定 › ZotMax ›「AI」分頁的「AI 服務」。它會存進 Zotero 的密碼管理，不寫進一般設定檔。

    打勾確認

    跟著 Zotero 裡的首次設定精靈走

    剛剛準備的東西，在這裡用上。精靈裡有四件事，每一步都可以略過：

    1. 選模式：新使用者建議「研究生引導」：自動找文獻、AI 寫草稿、評讀陪練和讀懂統計先關著，整理、評讀、搜尋照常可用。想全部打開就選「進階」。之後在 設定 › ZotMax ›「功能」隨時改。
    2. 指定筆記位置：選剛剛那個 Obsidian vault 的資料夾；貼上 Notion 的 token 和資料庫連結。
    3. AI（選填）：貼上剛剛申請的 API 金鑰，服務商選 Claude服務商選 OpenAI；金鑰存進 Zotero 的密碼管理。選「先不用 AI」，之後想用再回來。
    4. 試同步一篇：挑一篇有 PDF、最好有劃線的文獻，先試一篇確認都接上了。

    之後想換金鑰或服務商：設定 › ZotMax ›「AI」分頁 › AI 服務，服務商選 Anthropic（Claude），貼到「Claude API key」OpenAI（GPT / Codex），貼到「OpenAI API key」。

    先不用 AI：同步時選「同步但不呼叫 AI」，或在 設定 › ZotMax ›「功能」關掉「AI 文獻筆記」。

    想再打開精靈：按 Ctrl+Shift+P⇧⌘P 開快速指令，輸入「設定精靈」，選 設定精靈…。

    精靈沒有出現？手動設定

    打開設定：Edit›SettingsZotero›Settings…，左側最下面的 ZotMax；也可以從 Tools›ZotMax 設定… 直接打開。設定分成六個分頁：功能 · 同步 · 整理 · 找文獻 · 篩選與評讀 · AI；不知道在哪一頁，就在最上面的「找設定」打關鍵字。

    Obsidian（「同步」分頁 › Obsidian）

    1. 「Vault 資料夾路徑」按 選擇資料夾…，選 vault 的根目錄。
    2. 「預設子資料夾」保持 Zotero；「檔名格式」建議用 Citation key，沒有 citation key 的文獻會改用「作者 年份 - 標題」。
    3. 保持勾選「建立『Zotero 文獻庫.base』總表」：第一次同步後，vault 裡會出現文獻總表與閱讀進度看板。

    重新同步不會蓋掉你的筆記：外掛只更新 %% zotero-bridge:start %% 到 %% zotero-bridge:end %% 之間的內容，你的心得寫在最下面的「✍️ 我的筆記」。

    Notion（「同步」分頁 › Notion）

    1. token 貼到「Integration token」，資料庫連結貼到「預設資料庫連結」。
    2. 按 測試連線並補齊資料庫欄位。看到 ✅ 就完成了，外掛會自動建立 作者、年份、期刊、DOI、摘要、閱讀狀態、研究設計、證據等級 等中文欄位。

    欄位可以改名，但不要刪除或改類型：外掛記得每個欄位，改名後照樣寫得進去；你自己加的欄位（例如「評分」）外掛不會動。以前用英文欄位（Authors、Year…）的資料庫照常可用；想換成中文，按 把 Notion 欄位改成中文…，確認後才會改名。文獻比較表也要放進 Notion 的話，另建一個頁面、同樣用 Connections 加入 integration，再把連結貼到「文獻比較表的 Notion 父頁面」。

    AI（「AI」分頁 › AI 服務）

    1. 「服務商」選 Anthropic（Claude），金鑰貼到「Claude API key」。「思考深度（effort）」保持 medium 即可；high 比較仔細，也比較慢、比較貴。OpenAI（GPT / Codex），金鑰貼到「OpenAI API key」。模型保持預設即可；Codex 系列是寫程式用的模型，整理文獻用一般模型效果較好。
    2. 「全文最多送出字元數」預設 150,000；設成 0 就只送摘要與劃線，比較省錢。

    先不用 AI：在「功能」分頁關掉「AI 文獻筆記」。

    1. 側邊面板：選一篇文獻（或在 PDF 閱讀器裡），按右側面板右緣的橋形圖示，就是這一篇的 ZotMax 面板：重點、你的劃線、閱讀狀態與評讀，下面的「動作」直接同步這一篇。

    3. 工具列按鈕：文獻清單上方、新增筆記 右邊的 ZotMax 按鈕（右鍵 › ZotMax 也一樣），依「同步、整理、找文獻、篩選與評讀、AI 輔助與寫作」分組，最下面是設定。

    自己做完，再請 AI 對照

    這兩個在「研究生引導」預設關著，要用時到 設定 › ZotMax ›「功能」打開，也要先有 API 金鑰。都會呼叫 AI、依用量付費。

    1. 評讀陪練：在文獻評讀表自己答完 CASP／JBI 每一題，按「對照 AI」。AI 只看原文、看不到你的答案，ZotMax 只列出跟你不同的題目，改不改由你決定。
    2. 讀懂統計：在 PDF 選一段看不懂的統計（OR、95% CI、p 值…），按選取框裡的 ZotMax：解釋統計，面板多出「統計解釋」；AI 寫的每個數字都和原文核對。

    • 自動同步：設定 ›「同步」分頁 › 自動同步，條目、劃線或筆記一變更就同步（不會自動呼叫 AI）。
    • 閱讀進度看板：打開 Zotero/Zotero 文獻庫.base，在「閱讀進度」拖曳卡片，就能更新待讀／閱讀中／已讀／已引用。
    • 分流規則：不同文獻庫或分類放到不同地方，見上一步的「手動設定」。
