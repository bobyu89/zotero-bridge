# Zotero Bridge 網站視覺系統

適用 `site/` 的三頁：`index.html`（首頁＋安裝精靈）、`search.html`（醫學文獻快速搜尋）、`appraisal.html`（文獻評讀表）。產品定位與語氣見根目錄 `PRODUCT.md`。共用樣式在 `site/zb.css`，各頁的 `<style>` 只放版面與該頁專屬元件。

## 世界：交班單與印章

使用者是台灣的護理研究生，也是臨床護理師。網站借用病房最熟悉的兩樣東西：

- **交班單**：把工作交給下一班時，寫清楚「交出去的」和「自己留著的」。首頁上半就是一張交班單：左欄「交給 Zotero Bridge」是印刷字（工具做的事），右欄「留給你」是手寫字（找文獻、評讀、寫作），把產品定位直接畫出來。
- **印章**：確認與判定才蓋章。這是全站唯一的招牌動作（signature move），只出現在「你做了決定」的地方：
  - 首頁交班單：「研究生引導 預設」
  - 安裝精靈：一步的勾全部打完時，卡片右上蓋「已確認」；最後一步「設定完成」
  - 評讀表：選定整體判定時，在判定按鈕旁蓋「納入／排除／需更多資訊」

工具頁（搜尋、評讀）是 Operate 模式：這個世界只提供字體、色彩、密度和印章，不改變版面、導覽或控制元件；控制元件一律是標準的按鈕、輸入框、下拉選單、核取方塊。

光線情境：白天在教室、圖書館用筆電（淺色）；大夜班休息時在護理站用手機（深色）。兩種主題都跟著 `prefers-color-scheme`，也可用 `<html data-theme="light|dark">` 強制。

## 色彩（`zb.css` 的 `:root`）

策略：Restrained，中性色帶冷灰藍（表單紙），加原子筆藍做動作色；朱紅只給印章。頁首色帶是深墨藍，讓每頁有一致的外框。

| Token | 淺色 | 深色 | 用途 |
|---|---|---|---|
| `--paper` | `#EDF1F5` | `#0E1420` | 頁面底色 |
| `--surface` | `#FFFFFF` | `#161E2E` | 卡片、輸入框 |
| `--panel` | `#E2E8EF` | `#1C2638` | 第二層中性色：步驟軌、表頭、程式碼底 |
| `--ink` | `#152033` | `#E5EAF2` | 主要文字 |
| `--ink-2` | `#47556B` | `#A5B1C4` | 次要文字（對 paper／surface／panel ≥ 6:1） |
| `--line` | `#C9D3DF` | `#2B374D` | 分隔線、卡片框 |
| `--line-strong` | `#8593A7` | `#5E6E8A` | 輸入框、次要按鈕框（對 surface ≥ 3:1） |
| `--pen` | `#2741A6` | `#9DB4FF` | 主要動作、連結、選取、焦點環 |
| `--pen-soft` | `#E3E9FB` | `#22305A` | 選取／會開啟的底色 |
| `--seal` | `#C0352A` | `#FF8A78` | 只用在印章 |
| `--mast` | `#16233F` | `#0A0F19` | 頁首色帶、PICO 字母、工具家族標籤 |
| `--yes` / `--no` / `--unclear` / `--na` | `#17703F` / `#B3261E` / `#875800` / `#56627A` | `#6FD39B` / `#FF8F84` / `#F1C060` / `#A5B1C4` | 評讀答案、判定、狀態（各有 `-soft` 底色） |

所有文字組合都達 WCAG AA（最低：`--seal` 對 `--seal-soft` 4.63:1）。狀態色不單靠顏色：答案按鈕有文字，燈號有 ✓ ✗ ? 符號，不一致的題目有文字標示。

## 字體

- `--font-hand`：**LXGW WenKai TC**（霞鶩文楷 TC，Google Fonts，台灣字形），備援 Kaiti TC／標楷體。只用在：首頁大標與段落標題、交班單「留給你」欄、工具頁 h1、印章。像學長姐手寫的提點。
- `--font-ui`：系統字（-apple-system、Segoe UI…），中文依序 PingFang TC → Microsoft JhengHei → Noto Sans TC（網路字型，只在沒有前兩者的系統下載）。所有標籤、按鈕、內文、資料。
- `--font-mono`：系統等寬字，只用在檢索式、程式碼、κ 值。
- 字級（工具頁固定 rem 階）：12 / 13 / 14 / 15 / 16（內文）/ 19（卡片標題）/ 24 / 30（工具頁 h1）。首頁大標 `clamp(28px, 7.4vw, 60px)`。中文內文行高 1.7。
- 全站 `font-variant-numeric: tabular-nums`。

## 元件與狀態

- **頁首色帶 `.mast`**：品牌（`bridge.svg` 圖示）＋站內導覽。工具頁左側固定是「← Zotero Bridge 安裝精靈」（測試依賴這段文字與 `<a href>` 的寫法），右側是另一個工具與目前頁面。導覽連結裡的 🔎 📋 是測試鎖定的文字，其他地方的圖示一律用內嵌 SVG（1em、stroke 2）。
- **按鈕 `.btn`**：主要（原子筆藍實心）、`.ghost`（白底框線）、`.small`。高度 40px，觸控裝置 44px（small 38px）。hover 換框色、active 下壓 1px、disabled 45% 透明、focus 2px 原子筆藍外框。
- **表單**：輸入框 1px `--line-strong` 框、8px 圓角、focus 時藍框＋3px `--pen-soft` 光暈；核取方塊用 `accent-color`。
- **提示 `.note`**：`tip`（綠）、`warn`（琥珀）、`info`（中性）。整塊淡底加 1px 同色框，不用側邊色條。
- **展開 `details.more`**：CSS 畫的 chevron，展開時旋轉。
- **表格**：表頭用 `--panel`，窄螢幕外層 `.table-wrap` 橫向捲動（搜尋頁狀態表改成一列一卡）。
- **印章 `.seal`**：雙框、朱紅、手寫字、旋轉 −5°；`.press` 在狀態改變時播一次「蓋下去」（0.38s，ease-out），減少動態時直接出現。
- **安裝精靈步驟軌**：桌機是直線串起的編號站點（目前步驟白底、完成步驟實心藍）；窄螢幕改成一排站點，上一步／下一步固定在畫面底部。
- **評讀答案 `.seg`**：分段按鈕，選中時整格填入答案色；雙人評讀不一致的題目整題琥珀底＋框＋文字。
- **燈號 `.dot`**：答案色實心圓＋符號；`.off` 為雙人不一致的外圈。判定標籤 `.vtag` 是同色框線小章。
- **toast**：畫面底部中央，深色底。

## 版面

- 內容最寬 1120px，左右 16px（`--gutter`），360px 寬無橫向捲動。
- 首頁：交班單 → 功能組合開關表 → 兩個網頁工具 → 驗證紀錄 → 安裝精靈。
- 搜尋頁：搜尋卡（整寬）→ PICO（左）＋已存檢索、EZproxy（右，900px 以下改單欄）→ 網址狀態。
- 評讀頁：論文資料、逐題評讀（進度列黏在上方）、判定與輸出（左）＋論文清單（右，900px 以下移到最上方）→ 燈號總覽。列印只印 `#printArea`（黑白表格）。

## 不做的事

不用 kicker／eyebrow 小標、不用漸層字、不用側邊色條、不用 emoji 當圖示（測試鎖定的導覽文字除外）、不放使用者見證或使用數字、不放 API 金鑰、不寫模型名稱。外部資源只有 Google Fonts。
