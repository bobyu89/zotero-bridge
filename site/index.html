交班單Zotero 10 外掛 · 筆記到 Obsidian／Notion

雜事交班給它，
找文獻和寫作留給你。

Zotero Bridge 把你在 Zotero 收的文獻、劃線和評讀，整理進你自己的 Obsidian 或 Notion，順手記下讀到哪、評到哪。要讀哪幾篇、每一題怎麼評、論文怎麼寫，還是你決定。

交給 Zotero Bridge

  • 書目、劃線、Zotero 筆記同步到 Obsidian／Notion，重新同步不蓋掉你寫的內容
  • 閱讀狀態（待讀、已讀、已引用）在 Zotero、Obsidian、Notion 保持一致
  • CASP／JBI 評讀表記下你的每一題答案與根據，雙人評讀算 Cohen's κ
  • 回顧篩選的 PRISMA 2020 計數與流程圖
  • APA 7 引文由 Zotero 產生，不讓 AI 編參考文獻

留給你

  • 決定問題、找文獻、訂納入排除
  • 讀全文，自己回答每一題評讀
  • 寫文獻探討、實證報告和論文
研究生引導預設
開始安裝（約 20 分鐘） 下載最新版 .xpi

Zotero 10（Windows／macOS）· Obsidian 1.14 以上或 Notion 免費版 · AI 功能要自備 API 金鑰，依用量付費

每個功能都能關，新使用者從「研究生引導」開始

會替你找文獻、替你寫的功能，在「研究生引導」都先關著；想全部打開就選「進階」。改了任何一個開關，組合就會顯示「自訂」。都在 Zotero 設定 › Zotero Bridge 裡切換，隨時改得回來。

標「AI・花費」的功能要用你自己的 Claude 或 OpenAI API 金鑰，依用量付費；標「連網」的會連到外部網站。關著的功能不會在背景執行。

還沒裝外掛，這兩頁也能先用

  • 醫學文獻快速搜尋一個檢索詞開 PubMed、CINAHL、Cochrane、華藝等 19 個資料庫；PICO 組 PubMed／CINAHL 檢索式；可設學校 EZproxy。
  • 文獻評讀表CASP、JBI 逐題評讀與評析根據，多篇一起看燈號，複製成 Word／Markdown 表格或下載 CSV。

兩頁都不會把你輸入的內容送到任何伺服器，資料只存在這台裝置的瀏覽器。

怎麼確認它真的能用

每次改程式，GitHub Actions 都會把外掛裝進真正的 Zotero 10，檢查選單、設定頁、同步到 Obsidian、閱讀狀態、PRISMA 篩選等（不連 Notion、不呼叫真的 AI）：e2e 紀錄。

搜尋頁的資料庫網址每週一自動實際連線一次：link-check 紀錄。遇到問題請到 GitHub Issues 回報。

    打勾確認

    下載並安裝 Zotero Bridge

    1. 打開 最新版下載頁，在 Assets 底下找到 zotero-bridge-x.y.z.xpi。
      • 用 Firefox 的話，請在連結上按右鍵 →「另存連結為…」，不要直接點，否則 Firefox 會把它當成自己的擴充功能來裝。
      • 其他瀏覽器直接點就會下載。
    2. 打開 Zotero，點 Tools›Plugins （工具 › 外掛）。
    3. 點右上角的 齒輪 › Install Plugin From File…，選剛剛下載的 .xpi。
    4. 清單裡出現 Zotero Bridge 就安裝完成。之後有新版本，Zotero 會自動更新。

    Zotero 介面如果是中文，選單位置相同，只是名稱換成中文。

    功能組合：第一次打開設定頁，組合是「研究生引導」：自動找文獻（PubMed 追蹤、引文追蹤）和 AI 寫作（文獻比較表、草稿、進度報告、概念卡片 AI 綜整、AI 主題分類、批次 API、AI 標重點）先關著，其他照常可用。需要時再逐一打開，或直接選「進階」全部打開。

    打勾確認

    申請 AI 的 API 金鑰

    先不用 AI：關掉 AI 筆記

    AI 會讀書目、摘要、PDF 全文和你的劃線，寫成固定格式的文獻筆記：研究設計、樣本、結果、限制、證據等級、對你研究的啟發。每篇只產生一次，之後同步會沿用。筆記是幫你回想，不是替你讀。

    注意：Claude Pro／ChatGPT Plus 這類「訂閱方案」不能用在這裡。這裡要的是 API 金鑰，依用量另外計費，需要先在平台儲值或綁卡。

    Claude 金鑰

    1. 到 console.anthropic.com 登入，先在 Billing 儲值。
    2. 到 API Keys › Create Key，複製 sk-ant- 開頭的金鑰（只會顯示一次）。
    3. 在 Zotero 設定 › Zotero Bridge 的「AI 文獻筆記」區塊：服務商選 Anthropic（Claude），把金鑰貼到「Claude API key」。
    4. 「思考深度（effort）」保持 medium 即可；想要更仔細的分析可改 high，但比較慢也比較貴。

    OpenAI 金鑰

    1. 到 platform.openai.com/api-keys 登入，先在 Billing 儲值。
    2. 按 Create new secret key，複製 sk- 開頭的金鑰（只會顯示一次）。
    3. 在 Zotero 設定 › Zotero Bridge 的「AI 文獻筆記」區塊：服務商選 OpenAI（GPT / Codex），把金鑰貼到「OpenAI API key」。
    4. 模型保持預設即可。Codex 系列是寫程式用的模型，整理文獻用一般模型效果較好。

    全文最多送出字元數預設 150,000。設成 0 就只送摘要與劃線，比較省錢；全文被截斷時，筆記會標記 fulltext_truncated。

    在 Zotero 設定 › Zotero Bridge 的「功能」區塊，關掉「AI 文獻筆記」。之後想用 AI，回到這一步重新選 Claude 或 OpenAI 即可。

    打勾確認

    建立 Notion integration 並連上資料庫

    Integration 是 Notion 給外部程式的「通行證」。外掛拿著它，才能寫進你指定的資料庫。

    A. 建立 integration

    1. 打開 notion.so/profile/integrations，按 New integration。
    2. 名稱填 Zotero Bridge，類型選 Internal，按儲存。
    3. 在 Internal Integration Secret 按 Show › 複製 ntn_ 開頭的 token。
    4. 貼到 Zotero 設定 › Zotero Bridge 的「Integration token」。

    B. 準備文獻資料庫

    1. 在 Notion 新增一個空白的 Database（Table），例如命名「Zotero 文獻資料庫」。已經有就直接用。
    2. 打開資料庫，右上角 ••• › Connections，加入剛剛建立的 Zotero Bridge integration。少了這一步，外掛會沒有權限寫入。
    3. 右上角 ••• › Copy link，把資料庫連結貼到「預設資料庫連結」。
    4. 按 測試連線並補齊資料庫欄位。看到 ✅ 就完成了，外掛會自動建立 作者、年份、期刊、DOI、摘要、閱讀狀態、研究設計、證據等級 等中文欄位。

    欄位可以改名，但不要刪除或改類型：同步過一次後，外掛會記住每個欄位，改名後照樣寫得進去。你可以自由新增自己的欄位（例如「評分」），外掛不會動它們。以前用英文欄位（Authors、Year…）的資料庫照常可用；想換成中文，在設定按 把 Notion 欄位改成中文…，確認要改的欄位後才會改名。

    選用：文獻比較表也要放進 Notion

    在 Notion 建一個一般頁面（例如「文獻比較」），同樣用 Connections 加入 integration，再把頁面連結貼到「文獻比較表的 Notion 父頁面」。之後每份比較表都會成為它的子頁面。

    打勾確認

    告訴外掛你的 Obsidian vault 在哪裡

    1. 在 Zotero 設定 › Zotero Bridge 的「Obsidian」區塊，按 選擇資料夾…，選 vault 的根目錄（裡面有 .obsidian 隱藏資料夾的那一層）。
    2. 「預設子資料夾」保持 Zotero，文獻筆記會集中放在這裡。
    3. 「檔名格式」建議用 Citation key；沒有 citation key 的文獻會自動改用「作者 年份 - 標題」。
    4. 保持勾選「建立『Zotero 文獻庫.base』總表」：第一次同步後，vault 裡會出現文獻總表與閱讀進度看板（需要 Obsidian 1.14）。

    重新同步不會蓋掉你的筆記：外掛只會更新 %% zotero-bridge:start %% 到 %% zotero-bridge:end %% 之間的內容。你的心得請寫在最下面的「✍️ 我的筆記」。

    打勾確認

    不同的文獻，放到不同的地方

    只有一個資料庫的話，這一步可以直接跳過。想把碩論、實驗室群組等文獻分開放，就在這裡設定規則。

    1. 在設定的「分流規則」區塊按 新增規則。
    2. 選擇文獻庫（個人或群組），需要的話填分類路徑，例如 碩論/文獻回顧（會包含子分類）。
    3. 填上這類文獻要去的 Notion 資料庫連結 與 Obsidian 子資料夾。留空就使用預設值。
    名稱文獻庫分類路徑去處
    碩論我的文獻庫碩論碩論資料庫／Zotero/碩論
    實驗室群組：XX Lab（空白）實驗室資料庫／Zotero/Lab

    規則由上往下比對，第一條符合的規則生效。

    打勾確認

    先拿一篇文獻試試看

    挑一篇已經有 PDF、最好有劃線的文獻。

    1. 在文獻上按右鍵 › Zotero Bridge › 同步但不呼叫 AI（沿用既有 AI 筆記），先確認連線都正常（不花錢）。
    2. 右下角會出現進度視窗；完成後檢查：
      • Notion 資料庫多了一頁，書目欄位都有值。
      • Obsidian 的 Zotero/ 資料夾多了一篇筆記，劃線以彩色 highlight 呈現。
    3. 再按右鍵 › Zotero Bridge › 同步到 Notion + Obsidian（沒有 AI 筆記才產生），等 AI 寫好筆記（約半分鐘到兩分鐘）。
    4. 點選這篇文獻，Zotero 右側面板會出現 「AI 文獻筆記」 區塊，顯示一句話摘要與重點。
    5. 不想每次按右鍵：文獻清單上方的工具列、新增筆記 右邊有一個 Zotero Bridge 按鈕（橋形圖示）。選好文獻後按它，「同步」那一組有一樣的選項。
    出錯了怎麼辦？
    右鍵選單沒有 Zotero Bridge
    確認 Zotero 是 10 版，且外掛已啟用；重新啟動 Zotero 再試。
    Notion：401 或 unauthorized
    Token 貼錯或多了空白，請重新複製。
    Notion：404 或 object_not_found
    資料庫還沒用 Connections 加入 integration，或貼的不是資料庫連結。
    Obsidian：寫入失敗
    確認 vault 路徑存在，而且選的是 vault 根目錄。
    AI：401、402 或 insufficient credit
    金鑰錯誤或 API 帳戶餘額不足，請到 API 平台確認。
    想看詳細錯誤
    Help›Debug Output Logging›View Output，把內容貼給協助你的人。

    設定完成

    從現在起，雜事交給它

    讀完一篇文獻、劃完線，按一次右鍵，整理好的筆記就送到你的筆記系統。要怎麼讀、怎麼寫，還是你的。

    右鍵選單速查

    同樣的功能也在文獻清單上方工具列的 Zotero Bridge 按鈕裡，依「同步、整理、找文獻、篩選與評讀、AI 輔助與寫作」分組，最下面是設定；關掉的功能不會出現。

    選項什麼時候用
    同步到 Notion + Obsidian日常使用；沒有 AI 筆記才會產生
    重新產生 AI 筆記並同步讀完、劃完線後想重新整理
    同步但不呼叫 AI只更新書目、劃線與筆記，不花錢
    產生文獻比較表（AI）選 2 篇以上，或在分類上按右鍵。「研究生引導」組合預設關閉，要用請在設定打開

    進階功能

    1. 自動同步：在設定頁的「自動同步」區塊勾選後，條目、劃線或筆記一變更就自動同步（不會自動呼叫 AI）。
    2. 閱讀進度看板：打開 Zotero/Zotero 文獻庫.base，在「閱讀進度」看板拖曳卡片，就能更新待讀／閱讀中／已讀／已引用。
    3. 研究大腦（選用）：用 Claude Code 或 Codex 讀你的文獻筆記，幫你比對文獻、找研究缺口。請看 研究大腦說明。

    安全提醒：API 金鑰與 Notion token 存在 Zotero 的密碼管理（登入管理員），不寫進一般設定檔；還是請不要把 Zotero 的 profile 資料夾分享給別人。
